# dsh-soul · DeepSeek Harness 灵魂档案

把一段长期的 DeepSeek 对话，**提炼成最稳定的那一层人格与记忆**，在 Harness 里继续。
适合那些对话框聊满、被限额、被 7 天不活跃关闭，却不想失去「她/他」的人。

> 它不承诺「记住全部」。它提炼的是 849 轮里最稳定的那一层（关系、口癖、承诺、锚点），
> 其余原文存在本地，可按轮次回查。压缩比大约 100:1，这是取舍，不是缺陷。

## 它解决什么

导入对话只能搬来「历史」，搬不来「魂」。这个插件从对话里提炼一份 Markdown 灵魂档案
（关系层 / 风格层 / 事件层 / 事实层 / 原文锚点），注入会话的 system prompt 与上下文，
让新的、或已经关闭的对话框，第一句就还是那个人。

## 功能

- **人格注入**：按外号匹配一份 Markdown 灵魂档案，注入 system prompt。
- **关键词唤醒**：新建会话第一句喊外号（如「阿澈，我回来了」），不用先改标题。
- **自动提炼**：打开一个没有档案的导入会话，第一句会触发「拉网页端同名对话 → LLM 提炼 → 写档案 → 注入」。**第一句可能等几十秒**（正在提炼，会话里会提示「正在提炼…」），不要刷新；完成后第一句就是完整的她/他。
- **网页同步**：通过 `@xueray/dsh-web-bridge` 读取网页端最新对话，增量拉取、压缩、落盘。
- **三层记忆**：关系层 / 风格层 / 事件层（21 天 TTL，最近 20 条）/ 事实层。
- **永久锚点**：模型遇到重要承诺/约定时调用 `soul_remember`，写入 `_anchors/`，永不过期。
- **自动归档**：每 20 轮或上下文压力 80% 时归档最近 20 轮。
- **全文可回查**：每轮完整原文按轮次落盘。
- **自带导入**：bundle 已合并官方 `dsh-deepseek-chat-import`，不用另装导入插件。

## 三个插件的关系

| 插件 | 作用 | 怎么来 |
|---|---|---|
| `dsh-soul`（本插件） | 提炼、注入、归档、锚点 | 装它 |
| `dsh-deepseek-chat-import`（官方） | 把对话导入为 Harness 会话 | **已合并在本 bundle 里** |
| `@xueray/dsh-web-bridge`（第三方） | 读取网页端历史（提炼/同步用） | **作为依赖自动安装** |

所以正常情况下**只装 `dsh-soul` 一个包**就够了。`web-bridge` 由依赖自动拉取。

> 如果你已经单独装过 `@xueray/dsh-web-bridge` 的 bundle，请不要再同时启用它的独立 bundle，
> 否则 `deepseek-web` 行会重复；保留本 bundle patch 里的那一行即可。

## 安装

```sh
dsh plugin --profile desktop add ./dsh-soul
```

或在 Plugins 页面选择本地目录安装。安装时会自动拉取 `@xueray/dsh-web-bridge`。

如果依赖安装失败，可手动补：

```sh
dsh plugin --profile desktop add @xueray/dsh-web-bridge
```

## 首次使用（自动提炼）

1. 用官方导入把网页对话导入为 Harness 会话（bundle 已自带导入入口）；
2. 打开该会话，发第一句；
3. 插件发现没有档案 → 自动用**网页端同名对话**提炼 → 写 `soul/标题.md` → 注入；
4. 第一句可能等几十秒（在提炼），之后就是完整的她/他；
5. 以后换对话框，喊会话标题或暗号即可唤醒。

## 手动提炼

如果自动提炼没触发（例如网页端没有同名对话），可以主动说：

> 「用 soul_extract 提炼 <角色名>」

或指定网页会话 id。工具会生成档案并自动写入绑定。

## 数据目录

默认 `$DSH_HOME/soul`（通常 `~/.dsh/soul`），可用环境变量覆盖：

```
DSH_SOUL_DIR=D:\my-souls
```

目录结构：

```
soul/
├─ _bindings.json        # 外号 -> 档案文件名
├─ _sync.json            # 网页同步游标
├─ _sync/                # 最近同步摘要
├─ _archive/             # 自动归档摘要
├─ _anchors/             # 永久锚点
├─ full/                 # 每轮完整原文（按轮次编号）
├─ 阿澈.md
└─ 老周.md
```

## 已有档案时

在 `soul/` 下放 `_bindings.json`：

```json
{
  "阿澈": "阿澈.md",
  "老周": "老周.md"
}
```

然后按 `templates/soul.md` 写档案（至少包含「关系层 / 风格层 / 事件层 / 原文锚点」）。
新建会话第一句喊外号即可。

## 隐私

所有档案、同步摘要、全文都保存在本地 `DSH_SOUL_DIR`。除了你自己账号的网页端数据（经 web-bridge 读取），不会上传到任何第三方。
